# Shop API

Бэкенд-приложение на FastAPI с базой данных PostgreSQL, полностью контейнеризированное с помощью Docker.

## Стек технологий и приобретенные навыки (Skills)

В ходе разработки данного проекта были освоены и применены на практике следующие технологии и концепции:

* **Python & FastAPI** — разработка производительного асинхронного API, проектирование эндпоинтов, валидация данных (
  Pydantic), работа с жизненным циклом приложения (`lifespan`) и конфигурация CORS/стандартов OpenAPI (Swagger).
* **SQLAlchemy ORM** — проектирование реляционной архитектуры БД, работа с моделями, декларативным базовым классом (
  `DeclarativeBase`), управление сессиями базы данных и построение оптимизированных запросов.
* **PostgreSQL** — конфигурирование реляционной СУБД, управление пользователями, правами и хранением данных в
  изолированных средах.
* **Docker & Docker Compose** — мультиконтейнеризация проекта, написание оптимальных `Dockerfile` (на базе `slim`/
  `alpine` образов), связывание сервисов (бэкенд + БД) в единую изолированную сеть (`bridge network`), управление
  переменными окружения и томами (`volumes`) для персистентности данных базы.
* **Управление конфигурацией (DevOps/Git)** — архитектурное разделение окружений (Docker env vs Локальный `.env`),
  тонкая настройка CI/CD потоков в Git с одновременным пушем кода в несколько удаленных репозиториев (GitLab/GitHub).

## Быстрый запуск

Для локального запуска всей экосистемы приложения вам понадобится только установленный Docker.

Выполните в терминале корневой папки проекта следующую команду:

```bash
docker compose up --build
```
